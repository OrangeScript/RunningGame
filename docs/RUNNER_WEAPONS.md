# Running 前向武器实现

普通自动射击沿世界 `+Z`，不搜索最近敌人、不转向鼠标、不追射身后的目标。没有敌人也会继续开火。玩家通过横移把弹道对准驻守敌人；默认多弹是窄幅并排的平行弹道。

`AutoCombat` 从 `PlayerStats` 生成攻击计划，再应用 `ItemManager` 的道具修正。基础弹速在应用道具前提高到 22 米/秒；原攻击范围增加 18 米，初始约 33 米，保留射程增益。火力门继续提高攻击伤害，多重射击来自道具。

## 实际命中

`Projectile` 每步对移动路径执行球形扫掠，兼顾出膛时已经重叠的碰撞体。球形查询识别敌人与 `IRunnerProjectileObstacle`，过滤其他道路、死亡目标、同一发已经命中的敌人。没有碰撞就继续飞，射程和寿命结束后移除。

- **穿透**：命中敌人后继续原方向，不自动挑选并追踪下一个目标。
- **回弹**：仅获得该能力后才启用；在同道路、射弹前方 45° 扇区寻找下一敌人，按实际新方向飞行，仍需碰撞命中，不能掉头打后方。
- **爆炸**：直接命中后触发范围伤害，同一爆炸对同一目标只处理一次，不跨道路；先复制敌人列表，避免击杀即刻脱离注册表导致迭代失效。
- **元素**：每次实际撞击才施加元素与反应倍率。双元素构筑按弹体交替使用前两种元素。
- **障碍**：完整掩体会挡弹；只有服务器弹体调用其伤害接口。穿透敌人的道具不会让普通弹无条件穿过实体障碍。

## 轻度追踪配置

`ProjectileSpec` 新增以下可组合字段，`Clone()` 完整保留它们：

| 字段 | 默认值 | 行为 |
| --- | --- | --- |
| `homingTurnRate` | 0 | 每秒最大转角；0 时完全不扫描目标。 |
| `homingMaxAngle` | 12 | 相对世界 +Z 的最大追踪偏角，运行时上限 20°。 |
| `homingAcquireRange` | 18 | 前方同道路目标的搜索范围。 |
| `obstacleDamageMultiplier` | 1 | 只乘障碍伤害，不影响敌人和 Boss 伤害。 |

例如轻追踪芯片可以设为 `28°/秒、12°、24米`。目标必须位于前方、锥角内并属于当前道路；不会追逐背后、远侧或隔壁道路的敌人。`RunnerProjectileSteering` 将获取目标与有限转向规则独立为纯函数，方便验证和未来复用。

## 联机边界

服务器生成真正的伤害弹体；所有者客户端立即生成预测特效，其他客户端按 RPC 的视觉配方重放。视觉配方不带伤害值，`isAuthoritative=false` 的弹体不会扣敌人或障碍生命。主机和所有者忽略重复的视觉 RPC。

弹体绑定发射者的关卡阶段，退出 Running / Combat 后清理；`Projectile.ClearLane(laneId)` 还可供换关统一清场。敌人原地死亡不会让所有射向它的普通弹突然消失，因为弹体不依赖一个锁定目标的生命周期。

## 验证接口

- `RunnerWeaponsValidator.Validate()`：直线默认、前向锥角、转率、道路隔离、构筑复制与无伤害视觉配方。
- `AutoCombat.FiredShotCount / LastShotDirection / LastMuzzlePosition`：实际自动开火观测。
- `Projectile.Direction / IsHoming / IsAuthoritative / LaneId / SourceClientId`：弹道与权威状态观测。
- `Projectile.InitializeForward(...) / Simulate(deltaTime)`：在真实 Play Mode 碰撞场景中验证对齐、错位、掩体、穿透和纯特效弹。

碰撞与伤害的最终验证应在运行中的 NGO 会话完成，不能只用方向公式替代真实敌人生命与障碍生命检查。
