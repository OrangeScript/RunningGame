# 持续前进的 Running · 2026-11-10

本轮按新的玩法要求调整普通道路：驻守敌人、前向实际弹道、沿途道具门和原地击杀掉落。此前“敌人追人、角色停车清怪、关内禁止获得永久道具”的规则由本轮设计替代。爬塔分支投票、道路终点三选一和最终 Boss 继续共用已有流程。

## 核心节奏

```text
选路 → 各自道路持续前进 / 自动前射
     → 横移对准驻守敌人，观察预告，躲避迎面弹
     → 过数值门 / 带图标的被动道具门
     → 击杀后敌人原地留下对应品质被动，靠近即获得
     → 掩体挡射线、可击碎箱和爆桶、周期危险带改变路线
     → 到达终点后各自三选一 → 下一次公开选路
```

默认射击不会锁定旁边或背后的敌人。轻追踪是明确的构筑能力，有前方视野、转向速度和最大偏角限制。跑过敌人可以继续前进，但会放弃其掉落；对齐射线、冒险拿掉落和安全绕行构成不同选择。

## 入口和操作

从 `Assets/Scenes/Bootstrap.unity` 启动，选择“独自出发”；联机由房主创建房间，其他玩家加入后选择“跑酷旅程”。每人一条独立道路，仍统一投票选择下一个爬塔节点。

| 操作 | 行为 |
| --- | --- |
| A / D、左右箭头 | 横移对准敌人、躲弹、选门和捡物品 |
| 自动 | 持续以 4 米/秒前进，并向前发射弹丸 |
| Space / 2 | 使用第一 / 第二个主动道具 |
| 道路终点 | 停在出口等待队友，然后各自三选一 |
| 全灭 | 显示结束界面，房主可“重新出发”，所有玩家可返回菜单 |

“重新出发”创建新一局，重置生命、护盾和构筑，重新生成路线图。当前 Play 内已经生成的旧实例不会重建，应停止 Play 后从 Bootstrap 进入本次版本；联机两端使用同一版本。

## 弹道决定命中

普通武器不扫描最近敌人作为瞄准目标，空路上也会射击；多重射击变成并排的前向弹道。基础弹速至少 22 米/秒，基础射程约 33 米，使用上一帧到下一帧的球形扫掠和起点重叠检测，因此打不中侧面的敌人、不能直接隔着掩体扣血，也不会在低帧率时穿过敌人。

- 穿透：沿原方向贯穿，最多结算一次同一敌人。
- 跳弹：只向同一道路前方扇区内的后续敌人折射，不能转身打背后。
- 轻追踪：微引导芯片提供 28°/秒转率、最大 12° 偏角、24 米获取距离。只获取同 lane 前方目标；接近目标时保留锁定，真正飞过目标后放弃。任何一帧都不会超出最终偏角。
- 元素：弹丸命中后产生元素和反应，双元素构筑交替发射。
- 爆炸：命中位置产生同路范围伤害；贴地扩散环替代遮挡道路的大实体球，爆炸特效不参与碰撞。

玩家客户端立即生成纯视觉弹，服务器独立处理真实弹体和命中；客户端视觉弹没有扣血或破坏权限。其余玩家从 RPC 接收发射表现。实现与测试接口见 [RUNNER_WEAPONS.md](RUNNER_WEAPONS.md)。

## 四类驻守敌人

| 旧枚举 / 当前角色 | 攻击方式 | 主要应对 |
| --- | --- | --- |
| Chaser / 驻守卫兵 | 固定 -Z 直射 | 横移离开其射线，进入自己的射击线 |
| Strafer / 扇射手 | 三路扇射，仍朝道路后方 | 读三条预告，选空隙穿行 |
| Charger / 狙击手 | 更长预告、锁定有限角度，发射后不追踪 | 诱导方向后换线，不能留在预告线上 |
| Ranged / 连射手 | 三发短连射，间隔 0.18 秒 | 一次完整让开弹流，避免过早切回原线 |

敌人固定不移动、不会贴身瞬时扣血，也不会挡住角色。进入前方约 32 米范围才启动，普通预告至少 0.65 秒，狙击额外增加 0.4 秒。敌弹速度限制在 9–13 米/秒，基础伤害约 8–12；同路掩体也能拦截敌弹。玩家跑过后敌人不回头追射；离开视野的漏杀敌人被清理，不触发死亡掉落。

每个战区通常生成 2–4 名敌人，按 seed 选种类、位置、生命浮动和节奏。生命随节点层数、道路进度、精英系数及类型增长；精英路保证有特殊驻守者。头顶的小名称和生命条帮助识别目标。冻结会打断预备动作，解冻后重新预告；已经发出的敌弹不会因为枪手死亡而凭空消失，未发出的后续连射会取消。

## 路上直接构筑

### 道具门

保留 `+ − × ÷` 火力门，并在纸色牌面上显示被动图标、名称和即时火力变化。每条道路在有可用被动时保证至少一个道具门，其余门按 seed 混合；较低即时火力的一侧优先获得被动，形成“现在的输出 / 长期构筑”的选择。带代价的门也必须有一个安全替代，避免强制二选一扣数值。

每组门每位玩家只能通过一次。判定依据角色中心在道路中线的左右侧，中线固定归左侧；即使身体同时碰到两个触发器，也不会由物理回调顺序随机选门。

火力最低为 1，不改变角色数量。Running 中，基准 20 火力对应 1 倍伤害；更高火力按平方根增长、最高 8 倍，负向门在基准以下仍有明显影响。这样 ×2 仍然有价值，早期两次倍增不会立即抹去所有敌人。

### 击杀掉落

每次真正击杀都在敌人原地生成一次物品，图标和品质颜色可提前识别，不弹出模态选择。服务器检查同 lane 的实际平面距离，默认 1.1 米内自动拾取，道具可以扩大到最多 3.5 米；不允许客户端自报“已经捡到”。

普通敌人以普通 / 精良为主并有少量稀有；精英特殊敌人更偏向稀有，并可能掉史诗。选择先排除已拥有道具及本路已经预留的门 / 未拾取掉落，减少连续重复。道具池耗尽或中途获得同一道具时，重复转换成可见的护盾碎片，而不是无声失败。碎片提供 3 / 6 / 9 / 12 点等品质对应护盾，护盾上限 40，不继续放大纯输出。

跑过后才被持续伤害击杀的敌人，物品仍在原地，可能来不及回收，这是向前玩法的取舍。身后离开视野的物品会清理；死亡清理、漏杀退场和换关清场不会产生伪击杀奖励。

关后仍有三选一；事件提供临时道具，主动道具仍通过结算 / 宝藏获得。普通门只出普通至稀有的被动；史诗可以来自精英特殊掉落或宝藏。来源位明确写入资产，并由 `ItemAcquisitionPolicy` 统一检查。

## 七类有区别的障碍

| 类型 | 机制 |
| --- | --- |
| 木箱 | 易碎、挡双方弹体，可射开通路 |
| 加固掩体 | 更耐打，可绕行或作为敌弹掩护 |
| 爆桶 | 被击破后同路爆炸，可打敌人与引发连锁，不误伤玩家 |
| 横移挡板 | 射线与碰撞区域随服务器时间横移 |
| 旋臂 | 周期扫过局部道路，需看位置绕行 |
| 周期激光 | 地面预告后激活，再进入安全窗口 |
| 伸缩地刺 | 折叠 / 预告 / 激活具有不同造型 |

所有障碍对角色都是触发器，不会卡住持续前进。每段保留约 3.5 米连续逃生肩，规划检查横移和旋转的完整运动包络；障碍行距、门前净空和至少 0.85 秒周期预告提供反应时间。敌人生成在障碍之后，检查整个运动范围，避免敌人和掉落埋进障碍内部。

逃生肩不是永久无敌线，敌人仍可朝该方向射击。拿额外掉落、打爆桶或换射击线往往需要离开最安全的一侧。

## 代码与网络边界

- `AutoCombat` / `Projectile` / `RunnerProjectileSteering`：前射、真实扫掠、受限修饰、客户端无伤害特效。
- `Enemy` / `CombatEncounter` / `RunnerEnemyProjectileSystem`：驻守 AI、先预告再发射、持续前进战区、独立于枪手生命周期的敌弹。
- `RunLootPolicy` / `RunLootDirector` / `RunItemPickupVisual`：纯选择规则、按服务器距离拾取、离线图像、一次性授予。
- `RunnerBuildStats` / `ModularItemDefinition` / `ItemManager`：同一道具在不同玩法的作用，不复制一套 ID 或 UI 资产。
- `RunnerObstaclePlan` / `RunnerObstacleRuntime` / `RunnerObstacleReplication`：纯生成计划、实际机制和可靠破坏状态。

物品消息带 GameManager 的网络对象身份；障碍状态使用 section 网络对象 ID、内容 seed 和索引，先到状态缓存到对应几何生成后应用。敌弹按服务器出生时间生成并可靠同步命中，避免依赖已经死亡对象上的 RPC。换路、终点和全灭会清理弹体 / 掉落，构筑保留，路线投票和等待不会额外消耗临时道具时间。所有玩法实例都由既有注册 prefab 或非 NetworkBehaviour 场景模块构成，没有在生成后临时增加未注册的 NetworkBehaviour。
